# Maré — Fashion Store Concept

**Live demo:** https://voialleestudio.github.io/mare-loja/

A concept e-commerce storefront for a beachwear and fashion brand, designed and built by [VOIALLE Estúdio](https://voialleestudio.com.br).

## Features
- Product showcase organized by category
- Size selection on each product
- Shopping bag with live totals and shipping calculation
- Checkout flow with PIX and other payment options
- Order handoff via WhatsApp
- Fully responsive, mobile-first layout

## Tech
Single-file HTML, CSS and vanilla JavaScript. No frameworks, no build step, fast to load and easy to host anywhere.

*Content is in Brazilian Portuguese. This is a concept project; the brand is fictional.*
